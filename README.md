# 太空梭雷切模型｜學思創客 XUESI MAKER

3D 分步組裝、插銷分離練習、發射模擬，並提供雷切檔下載（板厚 3 mm）。

## 檔案
| 檔案 | 說明 |
|---|---|
| `index.html` | 網站本體（3D 組裝體驗＋下載區＋說明），單一檔案 |
| `files/*.enc` | 加密後的雷切檔（5 個 SVG 與全部打包 ZIP），需在網頁輸入密碼才能下載 |
| `thumbs/*.png` | 下載區的預覽縮圖 |

下載區使用密碼保護：檔案以 AES-GCM 加密存放，輸入正確密碼後在瀏覽器內解密下載，伺服器上沒有未加密的雷切檔。更換密碼需要重新產生 `files/` 內的加密檔與 `index.html`。

雷切圖層：紅＝切穿、藍＝淺切線、黑＝深雕、綠＝淺雕。
